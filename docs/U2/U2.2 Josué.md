## Representación conceptual
```mermaid
graph TD
    %% Entradas
    subgraph Entradas
        S1[Sensor de Flujo]
        S2[Botonera / Interfaz]
    end

    %% Procesamiento / Control
    subgraph Control y Procesamiento
        MC{Microcontrolador ESP32/PIC}
        FW[Lógica de Firmware / Histéresis]
        MC <--> FW
    end

    %% Salidas / Actuadores
    subgraph Salidas
        A1[Válvula / Relé]
        A2[Pantalla LCD]
        C1[(Servidor Web / Nube)]
    end

    %% Conexiones
    S1 --> MC
    S2 --> MC
    MC --> A1
    MC --> A2
    MC --> C1
